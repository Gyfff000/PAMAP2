依据训练集三折验证的平均 Macro-F1，选定随机森林作为最终展示模型，其验证均值为 0.9105，样本标准差为 0.0082。在 2223 个测试窗口中，该模型正确识别 2048 个，错误 175 个，Accuracy 为 0.9213，Macro-F1 为 0.9261。交叉验证选择和最终测试结果一致，统计特征随机森林在四种主模型中均排名首位。

随机森林三个验证折的 F1 从 0.9026 到 0.9189，标准差为 0.0082。早期 CNN 和融合模型的折间标准差分别为 0.0704 和 0.0418，表明神经网络在不同验证片段组合上的成绩变化更大。各模型在相同窗口上比较，这种差异对应当前表示和训练设置下的验证稳定性。

早期 CNN 的验证均值为 0.7935，测试 F1 为 0.5693，融合模型对应为 0.8978 与 0.8526。融合模型的测试 F1 比早期 CNN 高 28.33 个百分点，比随机森林低 7.35 个百分点。这组结果表明，统计特征对当前活动任务具有较强区分度，与时序表示联合后也改善了网络的测试成绩。

融合模型同时引入三个部位编码器和统计分支，参数量由早期 CNN 的 19052 增至 35868。现有实验比较的是这两套完整配置。进一步量化各分支贡献时，可在统一参数预算下逐一移除分支，并保持划分、训练轮数和优化器设置相同。
